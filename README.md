# Real Gas Thermodynamic Property Calculator

**Course:** CHL2002 – Thermodynamics  
**Institute:** Indian Institute of Technology Delhi

## Overview

This project presents a Python-based graphical application for calculating thermodynamic properties of real gases using cubic equations of state (EOS).

The application provides an interactive dashboard where users can select a gas, choose an equation of state, enter temperature and pressure, and calculate the corresponding thermodynamic properties.

## Features

- Supports four cubic equations of state:
  - Van der Waals (VDW)
  - Redlich–Kwong (RK)
  - Soave–Redlich–Kwong (SRK)
  - Peng–Robinson (PR)
- Calculates the compressibility factor (Z).
- Determines molar volume.
- Calculates fugacity coefficient and fugacity.
- Computes residual and total enthalpy and entropy.
- Displays pressure–volume isotherms.
- Provides a graphical interface using Python Tkinter.

## Technologies Used

- Python
- Tkinter
- Matplotlib

## How to Run

1. Install Python 3.
2. Install the required library:

   ```bash
   pip install matplotlib
   ```

3. Download `SOFTWARE.py`.
4. Run the application:

   ```bash
   python3 SOFTWARE.py
   ```
